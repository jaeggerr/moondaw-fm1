Prendre, copier, coller

Recopier une mesure, déplacer un accord, poser le même effet sur dix pas. Dans l'app, SÉLECT est un mode et un tap pose le second coin du rectangle. Ici le second coin, c'est le curseur : les deux potards de gauche l'emmènent, comme toujours. Sur PATTERN seulement pour commencer.

Cadre 1 · le mode allumé, le rectangle étendu

SELECT plante un coin, la main gauche emmène l'autre

Une pression sur SELECT (le bouton EDIT) : la case du curseur devient le coin fixe, le bouton s'allume en cyan. SELECT et ALGORITHM déplacent le curseur comme avant, et tout ce qui se trouve entre le coin et lui est pris, en ambre. Trois boutons changent de mot tant que le mode est allumé : COPY, PASTE, et CLEAR qui vide tout le rectangle. Une seconde pression sur SELECT lâche tout.

Ce qui est pris

Les champs couverts, pas des pas entiers : ici N1 à N3 de six pas, sans leur instrument ni leurs effets.

Ce qui se tait

Les quatre potards de droite et le clavier : dans le mode, on prend, on n'écrit pas.

Ce qui est dit

La taille dans la barre : SEL 3×6, champs × pas.

Cadre 2 · coller

PASTE colle là où est le curseur

COPY garde le rectangle allumé (on peut enchaîner CLEAR pour déplacer). Pour coller : on va où l'on veut, SELECT, PASTE. Ce qui a été copié se pose à partir de la case du curseur, vers le bas, et le mode s'éteint. PASTE est éteint tant que rien n'a été copié.

Ci-dessus : un seul effet copié (GAT 03), le curseur sur le FX2 du pas 08, SELECT vient d'être pressé. PASTE est allumé ; il posera GAT 03 dans ce slot sans toucher aux notes du pas.

Déjà tranché

  • 10/10 — validé et écrit (app/pattern.c, le presse-papiers dans app/edit.c) : le mode, le rectangle, COPY, PASTE, CLEAR, et les règles de collage de l'app.
  • CLEAR éteint le mode, comme PASTE. COPY le laisse allumé.
  • Changer de bloc avec PRESETS éteint le mode : ce qui était pris était de l'autre bloc.
  • La barre dit SEL 2x4 avec un x minuscule : la fonte n'a pas le signe ×.
  • Ce que PASTE n'a pas pu écrire n'est pas annoncé (les pas perdus en fin de bloc, un effet refusé). L'app le dit dans sa ligne d'état ; ici il n'y en a pas.

Ce que je propose, et pourquoi

  • Les règles de collage sont celles de l'app. Seuls les champs copiés sont écrits, le reste de la cible ne bouge pas. Ce qui dépasse la fin du bloc est perdu, rien ne reboucle au début. Un effet qui dirait deux fois la même chose sur un pas est refusé.
  • Un effet copié seul se pose dans le slot FX sous le curseur, quel que soit le slot d'où il vient.
  • Le curseur sur le numéro du pas prend le pas entier : notes, instrument, effets.
  • Ce qui est copié survit au changement de bloc, de piste et de phrase : c'est comme ça qu'on recopie une mesure ailleurs. Il s'oublie en ouvrant un autre morceau.
  • Un collage ou un vidage se reprend d'un seul UNDO.
  • Pas de COUPER : COPY puis CLEAR, deux pressions, le rectangle reste allumé entre les deux.
  • Dans le mode, LOOP et INSTR n'existent plus : leurs boutons disent COPY et PASTE. On sort du mode pour les retrouver.

Ce qui reste ouvert

  • PHRASE : son bouton EDIT dit OPEN, il n'y a pas de place pour SELECT sans déplacer quelque chose. Je ne propose rien tant que la sélection n'a pas servi sur PATTERN.
  • Transposer une sélection au potard (monter trois pas d'une octave) : tentant, puisque les potards de droite sont libres dans le mode. Pas dans l'app, donc pas ici.
