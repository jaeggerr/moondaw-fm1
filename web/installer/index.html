Installer MOONDAW sur votre FM-1

Cette page écrit le firmware dans la machine par USB, depuis Chrome ou Edge sur un ordinateur. Il n'y a rien à installer sur l'ordinateur.

Installer un firmware sur un FM-1 se fait à vos risques et peut laisser la machine incapable de démarrer (voir la dernière section). Branchez le FM-1 directement à l'ordinateur avec un câble USB de données, fermez les autres applications qui se servent du MIDI, et ne débranchez rien pendant l'écriture.

Sauvegarder les morceaux de la machine

Quand le FM-1 tourne sous MOONDAW : tous les morceaux de sa flash, dans un seul .zip de fichiers .trk, enregistré sur cet ordinateur. Mettez d'abord la machine sur son écran MENU. Réinstaller MOONDAW laisse les morceaux en place ; revenir au firmware officiel, pas forcément.

Revenir au firmware officiel

Le firmware officiel M-VAVE V15, à partir du fichier non modifié FM-1_015.fwsc (699 956 octets) : il est dans le dépôt fm1_open de M-VAVE, dans sdk/firmware/. (Le FM-1.fwsc de m-vave.com est maintenant la V16, que cette page ne connaît pas.) Le fichier est vérifié dans ce navigateur et n'est envoyé nulle part. Seul ce fichier exact est accepté.

Sauvegardez les morceaux d'abord (ci-dessus) : le firmware officiel se sert de la flash où MOONDAW les range.

Si le FM-1 ne démarre plus

Cette page parle à un firmware qui tourne (ou au chargeur de mise à jour d'une installation coupée : elle la termine). Un FM-1 qui ne démarre pas n'a pas d'USB-MIDI, et le navigateur ne peut pas l'atteindre.

Après deux démarrages ratés, ou avec OCT− et OCT+ tenus 5 secondes sous MOONDAW, la puce entre dans son propre mode de mise à jour et apparaît sur l'USB comme WL80UBOOT1.00. Dans ce mode, c'est un périphérique de stockage de masse, une classe que les navigateurs n'ont pas le droit d'ouvrir (WebUSB la refuse, et le pilote disque de l'ordinateur la retient). Y remettre le firmware officiel demande un programme sur l'ordinateur :

  1. fm1_rescue.py de felucca-bsp (tools/) : du Python avec pyusb, lancé avec sudo sur un Mac, le même fichier V15. Sans --write il ne fait que lire et sauvegarder la flash ; avec, il écrit la V15.
  2. FM-1-transporter : un Seeed XIAO RP2040 câblé sur les broches USB du FM-1, pour quand plus rien ne répond.
Le détail

Vérifié ici avant que quoi que ce soit parte : l'identité du paquet, ses CRC, et qu'il porte le chargeur de mise à jour de Felucca (pour la V15 officielle : son SHA-256). Le FM-1 doit répondre comme un FM-1, et après l'installation il doit annoncer l'identité du paquet — FM-1_900 pour MOONDAW. Les identités vues jusqu'ici : FM-1_014, FM-1_015 les V14 et V15 officielles ; FM-1_917 Felucca 1.7 ; FM-1_900 MOONDAW.
