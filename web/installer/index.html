MOONDAW

A tracker for the M-VAVE FM-1. This page puts it on the FM-1 over USB, from Chrome or Edge on a computer. Nothing to install.

Connect the FM-1 directly to the computer with a USB data cable, and close any other app that uses MIDI. Do not unplug it while writing. Custom firmware is installed at your own risk: a failed install can leave the FM-1 unable to start (see the last section).

Save the songs on the FM-1

When the FM-1 runs MOONDAW: every song in its flash, in one .zip of .trk files, saved to this computer. Put the FM-1 on its MENU screen first. Installing MOONDAW again leaves the songs where they are; returning to the official firmware may not.

Return to the official firmware

The official M-VAVE firmware V15, from the unmodified file FM-1_015.fwsc (699 956 bytes): it is in M-VAVE's fm1_open repository, sdk/firmware/. (The FM-1.fwsc on m-vave.com is now V16, which this page does not know.) The file is checked in this browser and not sent anywhere. Only that exact file is accepted.

Save the songs first (above): the official firmware uses the flash where MOONDAW keeps them.

If the FM-1 does not start

This page talks to a running firmware (or to the update loader of an install that was cut off: then it finishes it). An FM-1 that does not start has no USB-MIDI, and the browser cannot reach it.

After two failed starts, or with OCT− and OCT+ held for 5 seconds on MOONDAW, the chip enters its own update mode and shows up on USB as WL80UBOOT1.00. In that mode it is a USB mass-storage device, a kind of device browsers are not allowed to open (WebUSB blocks it, and the computer's disk driver holds it). Putting the official firmware back from there takes a program on the computer:

  1. fm1_rescue.py from felucca-bsp (tools/): Python with pyusb, run with sudo on a Mac, the same V15 file. Without --write it only reads and backs up the flash; with it, it writes V15.
  2. FM-1-transporter: a Seeed XIAO RP2040 wired to the FM-1's USB pins, for when nothing else answers.
Details

Checked here before anything is sent: the package's identity, its CRCs, and that it carries Felucca's update loader (the official V15: its SHA-256). The FM-1 must answer as an FM-1, and after the install it must report the package's identity: FM-1_900 for MOONDAW. Identities seen so far: FM-1_014, FM-1_015 official V14, V15; FM-1_917 Felucca 1.7; FM-1_900 MOONDAW.
